# Savvy

Desktop-приложение для постановки ссылок в очередь и скачивания через yt-dlp. Здесь описан язык обновления самого приложения.

## Обновление приложения

**Обновление приложения**:
Более новая версия Savvy, опубликованная как релиз на GitHub.
_Avoid_: апдейт, патч, апгрейд

**Проверка обновлений**:
Запрос к GitHub Releases о наличии версии новее установленной. Выполняется при запуске и затем дважды в сутки, пока приложение запущено; пользователь может запустить её вручную.
_Avoid_: поллинг, сканирование релизов

**Этап обновления**:
Одно из состояний найденного обновления: «доступно», «скачивается», «скачано».
_Avoid_: статус, фаза

**Индикатор обновления**:
Иконка в верхней панели, которая появляется при найденном обновлении и цветом показывает его этап.
_Avoid_: бейдж, кнопка обновления

**Список изменений**:
Очищенный перечень пунктов релиза, понятный пользователю: тип изменения и его описание, без ссылок, авторов и служебных записей.
_Avoid_: release notes, changelog, заметки о релизе

**Установка с перезапуском**:
Завершающий шаг: скачанное обновление заменяет текущую версию, и приложение запускается заново. Выполняется только по явному действию пользователя.
_Avoid_: автоустановка, тихое обновление

**Ручная загрузка**:
Режим, при котором приложение лишь ведёт на страницу релиза, потому что само скачать и установить обновление не может.
_Avoid_: ручное обновление
